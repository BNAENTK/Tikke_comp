# 오버레이 디자인 공유 — 체크리스트

경쟁사(외부 대조 사이트) 오버레이 갤러리를 tikke에 적용. 목표는 "내가 꾸민 오버레이를 남에게 그대로 넘기기".

## 정찰
- [x] 외부 대조 사이트 갤러리 구조 확인 — 카테고리 18종, 최신순/인기순, `@아이디`+버전 표기
- [x] 외부 대조 사이트 상세 페이지 확인 — 공유 코드 복사 / 페이지 링크 / 이 디자인으로 만들기 / 좋아요 / 신고
- [x] 핵심 메커니즘 = **공유 코드 문자열** → 앱 설정에 붙여넣기
- [x] tikke 기존 자산 확인 — 프리셋 시스템(설정 스냅샷+사운드+규칙) 이미 있음. **로컬 전용, 공유 불가**
- [ ] 오버레이별 설정 키 목록 확정 (지금은 flat 네임스페이스라 그룹이 없음)

## 1단계 — 공유 코드 (앱 안에서 완결)
- [ ] `OverlayCard`에 `configKeys` 추가 — 그 오버레이의 디자인을 이루는 설정 키
- [ ] 인기 오버레이부터 채움 (최고 후원자/목표/폭죽/레벨업/멀티 탑기프트/선물담기/타이머/전광판)
- [ ] 내보내기: 선택한 오버레이의 키만 뽑아 코드 문자열 생성
- [ ] 가져오기: 코드 검증 후 settings 반영 + 오버레이에 즉시 push
- [ ] 오버레이 카드에 `📋 공유 코드` / `📥 코드 붙여넣기` 버튼

## 2단계 — 웹 갤러리 (나중)
- [ ] 워커 저장소 + 목록/상세 API
- [ ] 웹 갤러리 페이지 (카테고리·정렬·미리보기)
- [ ] 좋아요 / 신고

## 하지 않는 것
- 외부 대조 사이트 디자인 자체를 가져오기 — 남의 사용자 창작물이다. 우리는 **구조**만 가져온다
- 기존 프리셋 시스템 교체 — 프리셋은 "내 전체 세팅", 공유 코드는 "오버레이 하나". 목적이 다르니 공존
