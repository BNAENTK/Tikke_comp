# 자막이 확정 안 되고 사라지는 문제 — 결정 노트

## 증상 (K)
"자막이 완성 안 되고 그냥 넘어가는 경우가 너무 잦아."
되물어 확인: **확정될 때 문장이 짧아짐**. 오늘 배포와 무관하게 **전부터 계속** 있었음.

## 먼저 확인한 것 (코드)
확정 카드는 Chrome 이 준 확정 문장을 **그대로** 그린다. 우리 쪽에서 자르는 곳은 없다.
```js
if (r.isFinal) { const t = r[0].transcript.trim(); ... onRecognized(t, promote); }
```
→ 짧아지는 건 Chrome 이 확정을 중간 자막보다 짧게 돌려주기 때문이다.

가능한 갈래가 둘이고 **고치는 방향이 정반대**였다.
- A: Chrome 이 문장을 끊어 확정 — 뒷부분은 다음 자막으로 이어짐(글자는 안 사라짐) → 카드 합치기
- B: 세션이 끊겨 뒷부분을 버림(글자가 진짜 사라짐) → 세션/미확정분 처리

K 판단으로 **B** 진행. 다만 K 의 근거는 관찰 인상이고 진단 스크립트로 측정한 값은 아니다
(콘솔 훅으로 1분이면 확정 가능 — 아래 "남은 검증" 참고).

## 실측으로 확인한 손실 지점 (추측 아님)
`translation.html` 에는 인식 세션이 죽는 자리가 둘 있고, **둘 다 떠 있던 중간 자막을 통째로 버렸다**.
1. `recog.onend` — Chrome 이 세션을 끝냄. 확정을 안 주고 끝나면 중간 자막은 12초 뒤 stale 타이머가 지운다.
2. `startSTT()` 안의 강제 재시작 — `recog.onend = null; recog.stop()`.
   워치독(45초 무이벤트), `audio-capture`/`network` 에러 재시작, 원어 변경이 여기로 들어온다.

시험으로 증상을 그대로 재현했다: 수정 전 두 경로 모두 **확정 카드 0개**(문장 증발).

## 적용
`flushPendingInterim()` — 확정 없이 세션이 끝나면 그때까지 들은 중간 자막을 확정으로 올린다.
떠 있던 카드를 그대로 승격해서 화면이 튀지 않는다.
정상 확정이 온 경우엔 그 경로가 이미 `releaseInterim()` 으로 버퍼를 비워 놔서 겹치지 않는다.

### 여기서 실측으로 잡은 부작용
`recog.stop()` 은 "멈추되 결과는 돌려달라"는 뜻이다. 그래서 건져낸 **뒤에** 옛 인식기가
확정을 늦게 보내고, 같은 문장이 두 번 떴다(시험 ⑤에서 실제로 재현).

막는 방법으로 "같은 문자열이면 무시"나 "N초 안이면 무시"는 **쓰지 않았다** —
짧은 말("네", "감사합니다")을 연달아 하면 진짜 두 번째 발화까지 삼킨다.
대신 **인식기 인스턴스 단위**로 막았다. 건져낸 인식기에 `_tkDead` 를 찍고,
그 인식기의 `onresult` 는 시작하자마자 반환한다. 오작동 여지가 없다.

## 시험 (9건, 전부 통과)
| | 내용 |
|---|---|
| ① | 수정 전: 확정 없이 끊기면 자막 증발(**증상 재현**) / 수정 후: 들은 데까지 남음 |
| ② | 정상 확정 뒤 세션 종료 → 중복 없음 |
| ③ | 침묵 중 세션 종료 → 빈 자막 안 생김 |
| ④ | 강제 재시작 경로도 ①과 동일하게 재현 및 해결 |
| ⑤ | 건져낸 뒤 옛 인식기의 늦은 확정 → 중복 없음 |
| ⑥ | 같은 짧은 말 연달아 두 번 → 둘 다 남음(중복 차단이 과하지 않음) |
| ⑦ | 세션 재시작 뒤 새 발화 정상 확정 |

기존 회귀 47건(렌더 23 + 속도 11 + 실 번역 13)도 전부 통과.

## 남은 검증 — 이건 아직 사실이 아니다
고친 손실 경로는 **실재하고 실측으로 재현했다**. 하지만 그게 **K 가 겪는 그 증상의 원인인지**는
아직 확인되지 않았다. Chrome 이 K 의 환경에서 실제로 확정 없이 세션을 끝내는지 안 봤기 때문이다.

확인법(배포·코드 변경 불필요). 자막 Chrome 창에서 F12 → Console:
```js
(() => {
  const log = [];
  const S = WebSocket.prototype.send;
  WebSocket.prototype.send = function (d) {
    try { const m = JSON.parse(d);
      if (m.type === 'translation' || m.type === 'translation_interim')
        log.push([m.type === 'translation' ? '확정' : '중간', m.payload?.subtitle?.original || '']);
    } catch (e) {}
    return S.apply(this, arguments);
  };
  window.__tkdump = () => console.log(log.map(([k, t]) => `${k} (${t.length}자) ${t}`).join('\n'));
})()
```
중간 자막이 길었는데 **확정이 아예 안 찍히면** B 확정(이번 수정이 맞음).
확정이 짧게 찍히고 **그 다음 중간 자막이 잘린 뒷부분부터 시작하면** A — 이번 수정으로는 안 없어지고
카드 합치기를 따로 해야 한다.
