## 도구 (scratchpad)
- `i18n-extract.js <파일>` — 번역 대상만 뽑는다(코드 조각 필터 포함)
- `merge-dict.js <번역.json> <섹션명>` — ja/en 에 병합. 기존 키는 안 건드림
- `i18n-wrap.js <파일>` — **사전에 있는 키만** t() 로 감싼다. JSX 텍스트 + title/placeholder 만.
  label:/name: 같은 데이터 속성은 제외 — 비교·저장에 쓰이는 값이 섞여 있어 자동 판단 불가
- `i18n-verify.js [키...]` — 사전 무결성(키 불일치·빈 번역) + 조회 확인
