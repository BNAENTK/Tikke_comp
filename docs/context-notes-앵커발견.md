# 리그 앵커 발견 — 결정과 이유 (2026-08-07)

## 문제
자정 리셋마다 하위 리그가 멈춘다. 어제 D4 88분, 오늘 D5 종일 0행 + D3·D1 230분.
원인은 **앵커 공급**이다. 컷·순위표는 그 리그에서 **방송 중인 사람**을 찔러야만 수집되는데,
자정에 승급·강등으로 명단이 통째로 갈리면 우리가 아는 사람이 그 리그에 없다.

실측(2026-08-07): 외부 대조 사이트 기준 오늘 D5 명단 56명 중 **44명이 우리가 한 번도 본 적 없는 사람**.
어제 D5 상위권 14명은 **전원 D4로 승급**해 있었다 — 그들을 찔러 봐야 D4 보드만 돌아온다.

## 왜 서버에서 못 하나 (전부 실측, 재시도 금지)
| 경로 | 결과 |
|---|---|
| 워커 fetch → 외부 대조 사이트 | 429 |
| 워커 헤드리스 브라우저 → 외부 대조 사이트 | 429 (`ENABLE_EXT_CUTOFFS=false` 사유) |
| 워커 → TikTok 라이브 목록 | 핸들 0개 (`ENABLE_LIVE_DISCOVERY=false` 사유) |
| 워커 → TikTok api-live | 챌린지 (정기점검 `부트스트랩=10` 감지 항목) |
| **주거 IP (K PC)** | **전부 통과** |

Cloudflare 데이터센터 IP 자체가 막힌다. 서버측 자체 발견은 불가능하다.

## 유료 대안 검토 결과 (전부 실측)
- **EulerStream** 무료 키는 서명만. `bulk_live_check`·`room_id` 는 **Business 전용**(월 $50).
  키 자체는 유효 확인(`/accounts/me` 200, 한도 일 1000/시 500/분 60).
  가격표에는 Community 포함으로 표시되나 API 응답은 Business 요구 — 표시가 실제와 다르다.
- **tik.tools** 리그 API 는 Ultra(주 $45 ≈ 월 28만 원). Pro 는 국가 톱100뿐이라 D리그를 못 본다.
- **voxo** 공개 API 는 핸들→리그 라벨뿐. 라이브·roomId 없음. 리그 랭킹은 PRO 로그인 뒤 —
  유료 기능 우회는 하지 않는다.
- **외부 대조 사이트** `islive_yn` 은 존재하나 정확도 42%(12명 표본 5명 실제 라이브)이고 데이터센터에서 429.

→ **K 결정: 일단 앱을 켜 두는 방식으로 간다.** 미니 PC / EulerStream Business 는 보류.

## 무엇을 고쳤나 — 시드 출처 교체
새 서비스를 만들지 않는다. `league-cutoff-harvester.ts` 가 이미 발견·폴링·보고를 다 한다.
문제는 **후보 출처 하나**였다.

- 기존: `user_league_data` — 과거 수확분이라 **승급하면 옛 리그로 남는다.** D5 를 찾으라 하면
  어제 D5(=오늘 D4)를 준다. 오늘 밤 정지의 직접 원인이다.
- 변경: `broadcaster_rank_snapshots` 오늘분 — **class_type 을 TikTok 응답에서 읽어 저장**하므로
  항상 현재 리그다. region='kr' 이 이미 걸려 있어 별도 한국 필터도 불필요하다.
  오늘 행이 없는 리그(D5 같은 교착)는 어제분으로 폴백한다.

`SEEDS_PER_LEAGUE` 12 → 30. 라이브 적중률이 10~40%라 12명으로는 목표 4앵커를 자주 못 채운다.
재발견은 TTL(25분) 만료 리그만 돌므로 매 회차 18리그를 다 훑지 않는다.

## 왜 이걸로 순위표까지 살아나나
`collectLeagueCutoff` 가 성공하면 `reportRoomToWorker` 로 그 방을 워커 풀에 등록한다.
워커는 그 방을 폴링해 **컷과 순위표를 함께** 저장한다. 즉 시드 품질만 고치면 둘 다 낫는다.

## 감시
별도 건전성 엔드포인트를 만들지 않는다. 정기점검 B(리그별 신선도)가 이미 실패를 드러낸다 —
발견이 멈추면 그 리그 `age_min` 이 올라간다. 검사를 두 벌 두면 갈린다.

## 한계 (그대로 남는 것)
- **앱이 꺼지면 멈춘다.** 서버측 경로가 전부 막혀 있어 이 방식의 본질적 제약이다.
- 새벽에는 라이브 자체가 적어 하위 리그 갱신이 느려진다. 후보를 늘려도 없는 사람을 만들 수는 없다.
- 완전 신규 방송인(우리 데이터에 한 번도 없는 사람)은 여전히 못 찾는다. 그들이 순위표에
  잡혀 우리 스냅샷에 오르면 다음 회차부터 후보가 된다(자가 치유, 다만 하루 단위로 느리다).
